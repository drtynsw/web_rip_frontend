# Лабораторная работа №6
## Тема: Оценка уязвимости системы

- **Цель работы**: Завершение интерфейса `пользователя` в `React`
- **Порядок показа**: **Скриншоты 1-2** Показать две страницы фронтенда с `mock` без запущенного сервиса. **Скриншоты 3-6** Показать 4 страницы фронтенда с запущенным бэкендом. **Скриншоты 7-8** Изменить данные в БД и показать изменения во фронтенде. **Скриншоты 9** Авторизация. Нажать F5 — состояние `Redux` вернулось в состояние гостя, но во вкладке `Application` сохранилась cookie сессии. **Скриншоты 10** Использовать значение cookie в `insomnia`/`postman` для получения плитки услуг с признаком `is_mine` для удаления. **Скриншоты 11-12** Показать все состояния `redux` в коде и `axios` в кодогенерации. **Скриншоты 13-14** Использование кода из кодогенерации в `thunk`, имена по теме. **Скриншоты 15-16** Вкладка `network`: адрес AJAX-запроса через `proxy`, названия и адреса изображений из `MinIO`
- **Контрольные вопросы**: схема redux-toolkit (reducer, store, middleware), axios, local storage. CORS и обратный прокси, BFF и GraphQL, Next.js и SSG, FSD
- **Диаграмма**: диаграмма прецедентов интерфейса `React`
- **Задание**: Добавление `Redux Toolkit`, авторизации и страницы добавления услуги, подключение к веб-сервису через `axios` и кодогенерацию

Фильтры плитки хранятся в `Redux Toolkit`, запросы к услугам выполняются через `redux-thunk` (`createAsyncThunk`) и сгенерированный из swagger клиент `axios`. Вход и выход выполняются обычным `axios` без кодогенерации и `thunk`, результат передаётся в `Redux` вручную. При недоступном бэкенде данные берутся из `mock`-коллекции, только в режиме гостя.

## Обратный прокси Vite (`vite.config.ts`)

| Префикс | Куда | Зачем |
|---|---|---|
| `/api` | `http://localhost:3000` | AJAX-запросы к веб-сервису NestJS на том же origin — без CORS, cookie `sessionId` отправляется автоматически |
| `/minio` | `http://localhost:9000` (префикс удаляется) | изображения и видео из S3 (MinIO): `http://localhost:9000/attack-vectors/x.png` → `/minio/attack-vectors/x.png` |

## Состояние Redux (`src/store`)

| Слайс | Поля | Actions / thunk |
|---|---|---|
| `user` | `username`, `isAuthenticated` | `setUser`, `logout` (вручную после axios) |
| `attackVectors` | `filterDate` (фильтр), `list`, `loading`, `isMock`, `pendingIds`, `error` | `setFilterDate`, `resetFilter`; thunk `getAttackVectorsList`, `deleteAttackVector`, `toggleLike`; при `logout` фильтр сбрасывается |
| `feed` | `current`, `loading`, `nextLoading`, `isLast`, `isMock`, `error` | thunk `getFeedItem`, `getNextFeedItem`; слушает `toggleLike` |
| `draft` | `draft`, `loading`, `error` | thunk `getDraft`, `createDraft`, `publishDraft`, `deleteDraft`; при `logout` сбрасывается |

`configureStore` подключает `redux-thunk` middleware и Redux DevTools. После F5 состояние возвращается к гостю, cookie `sessionId` остаётся в браузере.

## Меню (снизу)

| Пункт | Гость | Пользователь |

### Страница «Плитка» — `/`

Список опубликованных векторов атак в две колонки.

| Элемент | Тип | Что делает |
|---|---|---|
| Заголовок «Векторы атак» | текст | метка «демо-данные», если список из `mock` |
| Календарь (дата) | поле `date` | выбор года первой массовой фиксации; значение хранится в Redux (`filterDate`) |
| «Найти» | кнопка | `GET /api/attack_vectors?discovered_year=ГГГГ`; при недоступном сервисе у гостя — фильтр `mock`; во время запроса — анимация, кнопка заблокирована |
| «×» | кнопка | сбрасывает фильтр и обновляет список |
| Карточка | `Card` | изображение из MinIO (или по умолчанию), название; нажатие — лента `/feed/:id` |
| ♥ N | счётчик / кнопка | у гостя — счётчик; у пользователя — кнопка лайка `POST /api/attack_vectors/:id/like` |
| «Удалить» | кнопка | только у своих услуг (`is_mine = 1`): `DELETE /api/attack_vectors/:id` |

### Страница «Лента» — `/feed`, `/feed/:id`

| Элемент | Тип | Что делает |
|---|---|---|
| Видео | `video` | видео услуги из MinIO; если поле пустое или файл не загрузился — **видео по умолчанию** |
| Метка, название, описание, «больше / меньше» | текст, кнопка | поля услуги, разворачивание описания |
| «Опасность N / 10», «Год фиксации ГГГГ» | поля | `severity`, `discovered_year` |
| ♥ N | счётчик / кнопка | у пользователя — лайк / снятие лайка |
| «›» | кнопка | `GET /api/attack_vectors/feed?id=&next=true`; на последней услуге блокируется, надпись «Это последняя услуга в ленте» |

### Страница «Добавление вектора атаки» — `/add` (только пользователь)

| Элемент | Тип | Что делает |
|---|---|---|
| Название, изображение, видео | текст и два файла | шаг 1 |
| «Далее» | кнопка | `POST /api/attack_vectors` (`multipart/form-data`) — создаёт черновик; если черновик уже есть, открывается он |
| Краткая характеристика, базовая опасность (1–10), год фиксации | текст и два числа | шаг 2 |
| «Опубликовать» | кнопка | `PUT /api/attack_vectors/draft/publish`, переход в ленту на новую услугу |
| «Удалить черновик» | кнопка | `DELETE /api/attack_vectors/:id` |

### Страница «Вход» — `/login`

| Элемент | Тип | Что делает |
|---|---|---|
| Логин и пароль | текст и поле пароля | учётные данные |
| «Вход» | кнопка | `POST /api/users/login` через axios; браузер сохраняет cookie `sessionId`, в Redux записывается `setUser(username)`, переход на плитку |
