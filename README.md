# Лабораторная работа №5
## Тема: Оценка уязвимости системы

- **Цель работы**: Разработка базового SPA на React
- **Порядок показа**: **Скриншоты 1-3** Показать три страницы фронтенда с `mock` и вкладкой `network`. **Скриншоты 4-5** Показать реализацию изображения по-умолчанию. **Скриншоты 6-7** Объяснить код компонентов для фильтрации, передаваемые props, **Скриншоты 8-9** все используемые хуки. **Скриншоты 10** `Readme` для фронтенда
- **Контрольные вопросы**: react, props и состояние, компонент и элемент, useState и useEffect, жизненный цикл компонента, Vite и Babel
- **Расчет аппаратных требований** на 1 листе расчет аппаратных требований (число ядер, ОП, на 1 ядро по 4 ГБ ОП) по количеству пользователей и `rps`, а также требуемый размер жесткого диска с учетом прироста БД за 5 лет. Для расчета `rps` нужно взять количество `услуг` за день у одного пользователя, определить сколько HTTP `запросов` нужно выполнить для одной `услуги`, поделить на рабочее время пользователей. Для прироста БД описать в байта все поля таблиц `услуг`, а также объекты в `S3`. Расчет оформить формулами, в них указать ваши данные, а не общие переменные.
- **Задание**: Разработать три страницы фронтенд приложения на `React`, `TS` и подключить его к веб-сервису

Разработать базовый интерфейс приложения на `React` для `гостя`, аналогичный двум страницам из лабораторной работы №1 для просмотра `услуг`: `лента` и `плитка`. При этом на странице `плитка` списка `услуг` должен быть фильтр по теме (по дате, названию, цене и тд). Использовать компоненты `React-Bootstrap`. Для карточек предусмотреть изображение и видео по-умолчанию (в самом проекте), если поле в `услуге` пустое. Содержимое карточек получать только из коллекции с `mock`-объектами без бэкенда. 

В приложении должны быть снизу навигационная панель `navbar` из 4 пунктов (лента, добавление, плитка, Вход). При этом только два пункта являются доступными. В этой лабораторной никакого `Redux`, а `Context` вообще в курсе использовать нельзя. В `README` описать страницы приложения с кнопками и полями на них.

### Страница «Плитка» — `/`

Список опубликованных векторов атак в две колонки.

| Элемент | Тип | Что делает |
|---|---|---|
| Заголовок «Векторы атак» | текст | — |
| Календарь (дата) | поле `date` | выбор года первой массовой фиксации (берётся год из даты) |
| «Найти» | кнопка | применяет фильтр: `GET /api/attack_vectors?discovered_year=ГГГГ`, при ошибке — фильтр mock по `discovered_year`; дата сохраняется в адресе `?date=` |
| «×» | кнопка | сбрасывает фильтр (видна, когда дата выбрана) |
| Подсказка «Год фиксации: ГГГГ» | текст | показывает год, по которому идёт фильтр |
| Карточка | карточка `Card` | изображение (или изображение по умолчанию), название, число лайков ♥; нажатие — переход в ленту `/feed/:id` |
| «Ничего не найдено на выбранный год.» | текст | если по фильтру нет услуг |

### Страница «Лента» — `/feed`, `/feed/:id`

| Элемент | Тип | Что делает |
|---|---|---|
| Видео | `video` (autoplay, muted, loop) | видео услуги; если поле `video_url` пустое или файл не загрузился — **видео по умолчанию** `/DefaultVideo.mp4` |
| Постер видео | изображение | изображение услуги или **изображение по умолчанию** `/DefaultImage.jpg` |
| Метка «вектор атаки» | `Badge` | категория |
| Название | текст | `title` |
| Описание | текст | `short_description`, свернуто до 2 строк |
| «больше / меньше» | кнопка | разворачивает и сворачивает описание |
| «Опасность N / 10» | поле | базовая опасность `severity` |
| «Год фиксации ГГГГ» | поле | `discovered_year` |
| ♥ N | счётчик | число лайков (гость ставить лайки не может) |
| «›» | кнопка | следующая услуга: `GET /api/attack_vectors/feed?id=&next=true`; на последней услуге кнопка блокируется и появляется надпись «Это последняя услуга в ленте» |

### Используемые хуки

| Хук | Где | Зачем |
|---|---|---|
| `useState` | TilesPage, FeedPage | дата в календаре, список карточек, загрузка, текущая услуга, «больше/меньше», последняя услуга |
| `useEffect` | TilesPage, FeedPage | загрузка данных при открытии страницы и при смене фильтра / `id` |
| `useSearchParams` | TilesPage | дата фильтра в адресе `?date=` |
| `useNavigate` | TilesPage, FeedPage | переход в ленту по карточке, к следующей услуге |
| `useParams` | FeedPage | `id` услуги из адреса `/feed/:id` |
| `useLocation` | TabBar | подсветка активного пункта меню |
